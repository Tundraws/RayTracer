# RayTracerRTX

RayTracerRTX - учебный интерактивный трассировщик лучей в реальном времени на `C++`, `CUDA` и `NVIDIA OptiX`.

Программа рендерит 3D-сцену с аппаратной трассировкой лучей RTX. Поддерживаются аналитические примитивы, загружаемые полигональные модели, материалы, освещение, тени и интерактивное управление камерой и параметрами сцены.

## Возможности

- Рендеринг через NVIDIA RTX/OptiX.
- Сцена со сферами, плоскостью и полигональными моделями.
- Встроенные mesh-примитивы из треугольников: куб, пирамида и прямоугольная плоскость/панель.
- Загрузка OBJ/MTL, glTF/GLB и JSON-конфигов сцены.
- Материалы: матовый, зеркальный, металлический, стеклянный.
- Цветовые текстуры `map_Kd` в PPM/PNG/JPG.
- Карты нормалей, шероховатости и металличности для поддерживаемых материалов.
- Несколько объектов-сеток в сцене с положением, поворотом и масштабом.
- Настройка света, экспозиции, неба, качества и режима рендера.
- Режим реального времени и отдельный режим накопления сэмплов.
- Опциональный шумоподавитель OptiX для режима накопления.
- ImGui-панель управления и горячие клавиши.
- Тесты, замер производительности и Docker-check для учебной проверки.

## Требования

- Windows 10/11 x64.
- NVIDIA GPU с поддержкой RTX.
- NVIDIA Driver.
- Visual Studio 2022.
- CUDA Toolkit 13.1.
- NVIDIA OptiX SDK 9.1.

`NVIDIA Container Toolkit` для обычного запуска `RayTracerRTX.exe` не нужен. Он требуется только для GPU-приложений внутри Docker-контейнеров. В этом проекте Docker используется для проверки структуры, документации и CPU-тестов, а само RTX-приложение запускается напрямую в Windows.

## Сборка

1. Откройте `RayTracerRTX.sln` в Visual Studio 2022.
2. Выберите `Debug|x64` или `Release|x64`.
3. Проверьте, что установлены CUDA Toolkit 13.1 и OptiX SDK 9.1.
4. Соберите проект.

Сборка через MSBuild:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" RayTracerRTX.sln /p:Configuration=Debug /p:Platform=x64 /m
```

## Запуск

Обычный запуск из корня репозитория:

```powershell
.\x64\Debug\RayTracerRTX.exe
```

Запуск с OBJ-моделью:

```powershell
.\x64\Debug\RayTracerRTX.exe --mesh RayTracerRTX\assets\meshes\demo.obj
```

Запуск с JSON-сценой:

```powershell
.\x64\Debug\RayTracerRTX.exe --scene RayTracerRTX\assets\scenes\demo_scene.json
```

Дополнительные примеры:

```powershell
.\x64\Debug\RayTracerRTX.exe --scene RayTracerRTX\assets\scenes\material_showcase_scene.json
.\x64\Debug\RayTracerRTX.exe --scene RayTracerRTX\assets\scenes\textured_cube_scene.json
```

Если параметры не переданы, запускается стандартная демонстрационная сцена.

В переключателе сцен внутри приложения оставлены три понятных preset-сцены:
базовая сцена, сцена материалов и сцена с одной полигональной моделью. Другие
OBJ/glTF/GLB-модели пользователь добавляет через кнопку загрузки в панели.

## Управление

- `W/A/S/D` - движение камеры.
- `Space` - движение камеры вверх.
- Мышь - поворот камеры.
- `ЛКМ` - переключение между управлением камерой и панелью.
- `H` - показать или скрыть панель управления.
- `G` - переключить демонстрационный набор сцены/модели.
- `C` - сбросить камеру и свет текущей сцены.
- `F5` - перезагрузить текущую JSON-сцену с диска.
- `Q` - переключить качество.
- `P` - переключить режим реального времени и режим накопления.
- `N` - включить или выключить шумоподавитель.
- `Esc` - выход.

Часть параметров удобнее менять через ImGui-панель справа: материалы, свет, экспозицию, качество, сферы и загруженные модели.

Куб, пирамида и плоскость/панель представлены как `MeshData`, собранные из треугольников. Это позволяет использовать одну и ту же mesh-систему для встроенных фигур, стен, потолка, пола и загруженных OBJ/glTF-моделей.

## Входные данные

### JSON

JSON-сцена может задавать:

- камеру;
- свет;
- экспозицию;
- яркость неба и окружения;
- список mesh-объектов;
- положение, поворот и масштаб объектов;
- материалы;
- назначение материалов сферам и моделям.

### OBJ/MTL

Поддерживаемый subset:

- вершины `v`;
- нормали `vn`;
- текстурные координаты `vt`;
- треугольные грани;
- `mtllib` и `usemtl`;
- MTL-поля `Kd`, `Ks`, `Ns`, `Ni`, `d`;
- `map_Kd` для цветовой текстуры;
- `bump`, `map_Bump`, `norm` для карты нормалей;
- `map_Pr`/`map_roughness` и `map_Pm`/`map_metallic`.

OBJ mesh должен быть триангулирован. Многоугольные грани сейчас не разбиваются автоматически.

### glTF/GLB

Поддерживаемый subset:

- `.gltf` с внешним `.bin`;
- `.glb` с JSON/BIN-частями;
- позиции, нормали, UV и индексы треугольников;
- базовый цвет, металличность и шероховатость;
- базовые текстуры;
- простая иерархия узлов с положением, поворотом и масштабом.

Анимации, skinning, morph targets, embedded base64 buffers и сложные расширения glTF не поддерживаются.

## Панель управления

ImGui-панель содержит вкладки:

- `Сцена`;
- `Объекты`;
- `Материалы`;
- `Свет`;
- `Качество`;
- `Диагностика`.

Через панель можно выбрать сцену, загрузить OBJ/glTF/GLB, добавить или удалить сферу, изменить параметры сферы, настроить материал, свет, экспозицию, качество и шумоподавитель.

Вкладка `Редактор` позволяет добавлять объекты сцены: сферу, куб, пирамиду,
плоскость/панель и простой room preset из панелей пола, стен и потолка. Для
выбранной модели доступны положение, поворот и масштаб.

## Переносимый запуск

Проверка окружения на Windows-компьютере:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check_windows_environment.ps1
```

Создание переносимой Release-папки:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package_release.ps1
```

Скрипт создаёт `.release\RayTracerRTX-portable` и архив `.release\RayTracerRTX-portable.zip`.

В переносимой папке есть:

- `Check Environment.bat` - проверить зависимости;
- `Run RayTracerRTX.bat` - запустить демо-сцену.

CUDA Toolkit и OptiX SDK всё равно должны быть установлены на целевом компьютере.

## Структура проекта

- `RayTracerRTX/src/app` - приложение, сцена, камера, материалы, загрузчики.
- `RayTracerRTX/src/gpu` - OptiX/CUDA-рендерер и GPU-программы.
- `RayTracerRTX/src/common` - общие структуры CPU/GPU.
- `RayTracerRTX/assets/meshes` - демонстрационные модели и текстуры.
- `RayTracerRTX/assets/scenes` - JSON-сцены.
- `RayTracerRTX/tests` - тесты и замер производительности.
- `RayTracerRTX/docs` - расширенная документация.

Окно приложения создаётся через GLFW, интерфейс панели реализован через Dear ImGui.

## Ограничения

RayTracerRTX - учебный проект, а не production renderer. Реализация сфокусирована на демонстрации RTX-трассировки, загрузки полигональных моделей, материалов и интерактивного управления.

Текущие ограничения:

- OBJ поддерживает только треугольные грани.
- glTF/GLB поддерживается в ограниченном subset.
- Режим накопления может быть медленным и шумным на слабых GPU.
- Материалы являются упрощённой физически мотивированной моделью, а не полной PBR-системой.
- Docker-check не запускает GUI/OptiX-рендерер.

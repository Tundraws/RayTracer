# Чек-лист курсового проекта (вариант 42)

## Обязательные компоненты

- GPU-трассировка лучей в реальном времени (`C++`, CUDA, NVIDIA OptiX).
- Функциональная сцена: геометрия, материалы, источник света, тени и управление камерой.
- Описание сцены через аналитические примитивы, OBJ-модели и ограниченный набор glTF/GLB.
- История разработки в Git с осмысленными коммитами.
- Тестирование: модульные проверки и GPU smoke-тесты.
- Статический анализ и раздел о качестве.
- Документация: `README`, API, архитектура, тестовые результаты.
- Сведения о зависимостях и ограничениях безопасности.
- Описание применения AI-инструментов.
- CI-проверка для воспроизводимых CPU- и документационных проверок.

## Текущий набор тестов

- Проверки логики сцены:
  - значения по умолчанию;
  - переключение материалов;
  - ограничение координат;
  - обработка некорректных индексов.
- Проверки камеры:
  - нормализация и ортогональность базисных векторов;
  - резервное значение соотношения сторон;
  - влияние угла обзора на масштаб камеры.
- Проверки OBJ/MTL:
  - успешная загрузка модели;
  - отсутствие файла;
  - отклонение некорректной грани;
  - резервный режим при отсутствии нормалей;
  - несколько материалов;
  - чтение `Kd`, `Ks`, `Ns`, `Ni`, `d`;
  - сопоставление имён металлических и стеклянных материалов;
  - ограничение шероховатости, IOR и alpha;
  - чтение `vt`;
  - загрузка `map_Kd`;
  - загрузка `bump`, `map_Bump`, `norm`;
  - расчёт касательной основы для текстурированных треугольников.
- Проверки glTF/GLB:
  - минимальная модель `.gltf/.bin`;
  - параметры материалов;
  - минимальный `.glb`;
  - иерархия узлов и трансформации;
  - демонстрационный glTF-ресурс.
- Негативные сценарии:
  - отсутствующие OBJ/glTF-файлы;
  - отсутствующие MTL-файлы и некорректные MTL-значения;
  - отсутствующие, повреждённые и неподдерживаемые текстуры;
  - отсутствующие glTF-буферы;
  - некорректные JSON-сцены и трансформации;
  - запись предупреждений в консоль и `RayTracerRTX.log`.
- GPU smoke-тесты:
  - инициализация рендерера;
  - рендер одного кадра;
  - прогрессивное накопление;
  - сброс накопления при изменении камеры;
  - режим шумоподавителя OptiX;
  - проверка ненулевого буфера пикселей;
  - проверка неотрицательного GPU time.

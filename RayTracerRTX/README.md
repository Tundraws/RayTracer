# RayTracerRTX

RayTracerRTX - интерактивный RTX-трассировщик лучей.

Приложение рендерит 3D-сцену в реальном времени через NVIDIA OptiX/CUDA. Сцена может содержать сферы, плоскость и загружаемые полигональные модели. Параметры сцены задаются через JSON или меняются во время работы через панель управления.

Встроенные куб, пирамида и прямоугольная плоскость/панель создаются как mesh из треугольников. Панель можно использовать для пола, стен и потолка.

## Быстрый запуск

Из корня репозитория:

```powershell
.\x64\Debug\RayTracerRTX.exe
```

Запуск с OBJ:

```powershell
.\x64\Debug\RayTracerRTX.exe --mesh RayTracerRTX\assets\meshes\demo.obj
```

Запуск с JSON-сценой:

```powershell
.\x64\Debug\RayTracerRTX.exe --scene RayTracerRTX\assets\scenes\clean_floor_scene.json
```

Публичные preset-сцены в приложении: чистая сцена с большой плоскостью и сцена
с одной сферой в воздухе. Остальные OBJ/glTF/GLB-модели можно добавлять через
кнопку загрузки в панели; при наличии пола модель ставится на него и ищет
свободное место.

## Сборка

Требуется:

- Windows 10/11 x64;
- NVIDIA RTX GPU;
- NVIDIA Driver;
- Visual Studio 2022;
- CUDA Toolkit 13.1;
- NVIDIA OptiX SDK 9.1.

`NVIDIA Container Toolkit` для обычного запуска не требуется. Он нужен только для GPU-приложений внутри Docker-контейнеров.

Сборка через Visual Studio:

1. Откройте `RayTracerRTX.sln`.
2. Выберите `Debug|x64` или `Release|x64`.
3. Соберите проект.

Если OptiX установлен не в стандартную папку, путь можно переопределить через `OptixSdkDir` или `OPTIX_SDK_DIR`.

## Форматы входных данных

### JSON scene config

JSON-сцена задаёт камеру, свет, экспозицию, окружение, список объектов, transform-параметры и материалы.

### OBJ/MTL

OBJ mesh загружается через общий mesh-пайплайн.

Поддерживаются вершины, нормали, UV, треугольные грани, простое автоматическое разбиение граней с 4+ вершинами на треугольники, несколько материалов через MTL, `map_Kd`, карты нормалей, шероховатости и металличности.

Для граней с 4+ вершинами используется simple fan triangulation. Для сложных вогнутых многоугольников результат может быть неточным, поэтому такие модели лучше заранее триангулировать в 3D-редакторе.

### glTF/GLB

Поддерживается базовый импорт `.gltf`/`.glb`: геометрия, индексы, UV, материалы, текстуры и простые node transforms.

## Управление

- `W/A/S/D` - движение камеры.
- `Space` - движение вверх.
- Мышь - поворот камеры.
- `ЛКМ` - переключение между камерой и панелью.
- `H` - показать или скрыть панель.
- `G` - переключить демонстрационный набор.
- `C` - сбросить камеру и свет.
- `F5` - перезагрузить текущую JSON-сцену.
- `Q` - переключить качество.
- `P` - переключить режим рендера.
- `N` - включить или выключить шумоподавитель.
- `Esc` - выход.

## Панель управления

Панель Dear ImGui работает как компактный редактор сцены:

- слева выбирается сцена, объект, группа, свет, рендер или камера;
- справа редактируются свойства выбранного элемента;
- можно загрузить OBJ/glTF/GLB-модель, открыть или сохранить JSON-сцену;
- для выбранной модели можно назначить цветовую текстуру PNG/JPG/PPM;
- можно сохранить текущий кадр в PNG, JPG или BMP;
- раздел `Рендер` показывает FPS, GPU time, количество объектов, треугольников, материалов, режим качества, накопление и шумоподавитель.

Встроенные объекты редактора:

- сфера;
- куб;
- пирамида;
- плоскость/панель для пола, стен и потолка;
- пользовательская OBJ/glTF/GLB-модель через кнопку загрузки.

В редакторе также есть быстрые кнопки: удалить все модели, удалить все сферы,
очистить сцену и вернуть базовые объекты. Режим окружения создаёт открытую
сцену с полом, комнату из редактируемых панелей или пустую сцену без объектов.

## Диагностика

Приложение пишет предупреждения в консоль и в `RayTracerRTX.log`.

Если не найдена текстура, MTL-файл, карта нормалей или карта окружения, приложение использует безопасные значения по умолчанию. Если JSON-сцена или модель не загружается, приложение выводит ошибку и оставляет предыдущую или стандартную сцену.

## Переносимый запуск

Проверка окружения:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\check_windows_environment.ps1
```

Создание переносимой Release-папки:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package_release.ps1
```

В `.release\RayTracerRTX-portable` будут:

- `Check Environment.bat`;
- `Run RayTracerRTX.bat`;
- `RayTracerRTX.exe`;
- assets и runtime-файлы проекта.

CUDA Toolkit и OptiX SDK должны быть установлены на целевом компьютере.

## Структура

- `src/app` - приложение, состояние сцены, камера, ввод, ImGui-панель, JSON-конфиг, загрузчики OBJ/glTF/изображений, редактор сцены.
- `src/gpu` - OptiX/CUDA-рендерер, подготовка GAS/IAS, GPU-буферы, CUDA/OptiX device code.
- `src/common` - общие структуры CPU/GPU для материалов, вершин, параметров рендера и сцены.
- `assets/meshes` - модели и текстуры.
- `assets/scenes` - JSON-сцены.
- `tests` - модульные тесты, GPU smoke-tests и benchmark.
- `docs` - API, архитектура, результаты производительности, Docker-check и безопасность зависимостей.
- `third_party` - локальные сторонние header/source зависимости.

Окно создаётся через GLFW, панель управления - через Dear ImGui.

## Ограничения

- OBJ поддерживает треугольные грани и простое автоматическое разбиение граней с 4+ вершинами на треугольники.
- glTF/GLB поддерживается в ограниченном subset.
- Режим накопления может быть заметно медленнее режима реального времени.
- Материалы являются упрощённой физически мотивированной моделью.
- Docker-check не запускает GUI/OptiX.

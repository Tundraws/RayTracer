# Каталог проекта RayTracerRTX

Каталог содержит проект Visual Studio, исходный код, ресурсы, тесты и техническую документацию.

Основные инструкции по сборке, запуску, проверке и структуре репозитория находятся в корневом файле [README.md](../README.md).

## Состав каталога

- `src/app` – цикл приложения, состояние сцены, редактор, загрузчики ресурсов, камера и интерфейс;
- `src/gpu` – GPU-рендерер на NVIDIA OptiX/CUDA и пользовательские GPU-программы;
- `src/common` – структуры, общие для CPU- и GPU-кода;
- `assets` – демонстрационные модели, текстуры и JSON-сцены;
- `tests` – тестовое приложение с CPU-проверками и GPU smoke-тестами;
- `docs` – архитектура, API, статический анализ, зависимости и результаты измерений.
